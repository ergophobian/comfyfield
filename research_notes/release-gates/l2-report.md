## Audit findings by severity

1. **High — dependency advisories remain.** Windows `npm audit --json` reports two high and four moderate package findings: body-parser and Vite are high; esbuild, fast-uri, react-router and react-router-dom are moderate. Locations in this branch: `package-lock.json:1419`, `:1872`, `:2037`, `:2758`, `:2773`, `:3211`. High examples include Vite Windows filesystem-deny/path handling issues and body-parser compressed-body denial of service. This is an advisory inventory, not an exploit demonstration. Some suggested fixes require major upgrades; no automatic dependency changes were made.
2. **Medium — shipped third-party code and logos lack a complete release notice inventory.** `server/pack-patches/wanvideo/multitalk/wav2vec2.py:1` identifies a copied/patched Apache-2.0 source; the tree has no Apache license text, and NOTICE.md only covers ffmpeg. Twelve vendor-logo assets under `public/logos/` are used by `src/lib/brands.jsx:4`; their source/license/brand-use evidence is not recorded beside them. This is a documentation/rights-review gap, not a finding that vendor identification is inherently forbidden. Noto Sans has its source and OFL notice under `server/fonts/`.
3. **Medium — model/pack license research is present but release review is deferred/incomplete.** `research_notes/Open weight model lineup/audio_3d_llm.md:3` defers license review until after submission. `research_notes/engine/audio-talk/README.md:47` notes missing license metadata for Fill-ChatterBox and `:172` notes no license file for the Qwen-TTS pack. Runtime pins are in `shared/modelFiles.js:295`. Research also records custom/non-commercial/revenue/territorial terms; those notes are not evidence of completed release clearance. Weights are downloaded at runtime, not committed. No live upstream license verification or legal determination was performed.
4. **Medium, fixed — rejected inline Comfy key hid its own error.** At baseline `src/components/generate/ConnectComfy.jsx:27` treated the response object `{ ok: false }` as truthy and refreshed away the prompt. Commit `d1736b6` checks `test.ok` and leaves the error visible; the regression is in `scripts/format-ui-check.mjs`. Connections still labels a saved key “Connected” even after its test fails; that badge reflects configured storage rather than verified authentication and should not be used as provider proof.
5. **Medium, fixed — environment variants could be committed accidentally.** Baseline `.gitignore:2` covered only `.env`, although setup.md documents loading several variants. Commit `6544489` ignores `.env*` and explicitly retains `.env.example`; `.comfyfield/` remains ignored. No suspicious credential was found in the scanned reachable origin history.
6. **Low, fixed — package license field missing.** Baseline package.json omitted `license` while LICENSE and README stated MIT. Commit `6544489` adds matching SPDX metadata to the manifest and lockfile.
7. **Low / review gap — media clearance and research privacy are bounded.** No committed Higgsfield audit screenshots were found in the current tree or fetched history for its screenshot folder. The 422-image thumbnail pass showed ComfyField UI captures, generated art and vendor logos, with no obvious copied Higgsfield branding. Still art has prompt/source records in `research_notes/placeholder-assets-sources.json:1`; commit `d3fa1f5` calls it generated art. Commit `2d67d175ae06d6e20e134622de2afdc812bb6d14` identifies all 63 cover clips as generated via fal. These provenance claims and poster inspection do not establish every frame's rights. `research_notes/placeholder-assets-sources.json:5` and saved logs expose personal source paths; no sanitization or media removal was performed.

## Before making the repository public

1. Integrate or cherry-pick `6544489` and `d1736b6`; they remain local on `release-gates`.
2. Remediate the six dependency advisory findings, or record a concrete applicability assessment and release decision for each. Repeat build and full verification on the resulting release commit.
3. Complete the shipped third-party notice inventory: copied Apache patch, twelve provider logos, and the pinned model/node-pack license/use notes. Resolve the explicitly unknown-license cases before claiming unrestricted use of those integrations.
4. Have the owner approve media provenance/redistribution and the personal paths in research artifacts. Review the actual video footage where needed; decide any replacements/removals separately. This lane found no basis for deleting media automatically.
5. Repeat the redacted secret/history scan over the exact refs selected for publication after integration. No history rewrite or credential rotation is currently indicated by this scan.
6. Keep Docker marked untested until a Docker-equipped machine builds and starts it. This was an allowed skip, not a failed functional gate. Keep live-provider generation/quality/plan/billing claims unverified until a separately authorized live lane supplies evidence; no paid run is needed to repeat these free gates.
