# Video LoRAs for LTX-2.5 / LTX-2.3 / LTX-2 and MiniMax H3, mapped to ComfyField services (state on 2026-10-19)

Conventions used below. "dl30" = Hugging Face downloads in the last 30 days as returned by the HF API on 2026-10-19 (many community repos report 0 because downloads are not tracked, so likes are given too). Civitai "dl" / "up" = all-time downloads / thumbs-up on 2026-10-19; where a Civitai model has versions for several base models, the download count of the relevant version is given as "per-version". "Base" is copied from the model page. Confidence: H = official card with exact settings; M = community card with settings and examples; L = thin card, test release, or untested claim. Excluded on purpose and not listed: NSFW-focused LoRAs (including ones whose cards use "N54W"-style spelling for NSFW), LoRAs of real identifiable people or voice actors, and LoRAs named after living artists.

Data pulls behind this file: HF adapter trees via `https://huggingface.co/api/models?filter=base_model:adapter:<repo>&sort=downloads&limit=1000` for [Lightricks/LTX-2.5](https://huggingface.co/api/models?filter=base_model:adapter:Lightricks/LTX-2.5&sort=downloads&limit=1000), [Lightricks/LTX-2.3](https://huggingface.co/api/models?filter=base_model:adapter:Lightricks/LTX-2.3&sort=downloads&limit=1000), [Lightricks/LTX-2](https://huggingface.co/api/models?filter=base_model:adapter:Lightricks/LTX-2&sort=downloads&limit=1000), [MiniMaxAI/MiniMax-H3](https://huggingface.co/api/models?filter=base_model:adapter:MiniMaxAI/MiniMax-H3&sort=downloads&limit=1000), [Comfy-Org/MiniMax-H3](https://huggingface.co/api/models?filter=base_model:adapter:Comfy-Org/MiniMax-H3&sort=downloads&limit=1000); the [Lightricks author list](https://huggingface.co/api/models?author=Lightricks&limit=200&sort=downloads); Civitai API with `baseModels` = "LTXV 2.5", "LTXV 2.3", "LTXV2", "MiniMax H3" ([example](https://civitai.com/api/v1/models?types=LORA&sort=Most%20Downloaded&nsfw=false&limit=100&baseModels=MiniMax%20H3)). Every LoRA with its own catalog entry had its model card or Civitai page (API description) opened; exceptions, named by repo only from the Lightricks API list: LTX-2 19B Camera-Control Dolly-Out / Left / Right / Jib-Up / Jib-Down (the Dolly-In and Static cards were opened and share one template) and the LTX-2 19B Canny / Depth / Pose IC-LoRAs.

## 1. Which official Lightricks LoRAs and IC-LoRAs exist, and which load on LTX-2.5?

### Takeaway
Lightricks ships 15 LTX-2.5 adapter repos (14 declared on the LTX-2.5 adapter tree, plus Restore, which is declared on LTX-2.3 but named and tested for 2.5) and a distilled LoRA inside the main repo, aimed at editing, restoration, control and a few VFX-style effects (water, cinemagraph, slow motion), and states that "the large majority" of LTX-2.3 LoRAs and IC-LoRAs run on LTX-2.5 unchanged, which adds the LTX-2.3 Union Control, Motion Track, In/Outpainting, Relight, DubIt, HDR and Foley adapters. The official camera-control LoRAs (dolly in/out/left/right, jib up/down, static) and the canny/depth/pose/detailer IC-LoRAs exist only for LTX-2 19B, and community sources say LTX-2 LoRAs do not work on LTX-2.3 (so, by extension, not on 2.5).

### Cited Findings
Compatibility and base facts
- LTX-2.5 card: "Based on our testing, the large majority of LoRAs and IC-LoRAs trained on LTX-2.3 run on LTX-2.5 without changes. A small number of exceptions exist — validate your adapters before production use." — [Lightricks/LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5)

- Popularity of base repos (dl30, 2026-10-19): LTX-2.5 2,019,834 (8,436 likes); LTX-2.3 899,938; LTX-Video (0.9.x) 789,517; LTX-2 274,110 — [Lightricks author list](https://huggingface.co/api/models?author=Lightricks&limit=200&sort=downloads)

### Inferences
- Official LTX-2.5 work favours post-production (restore, matte, HDR, relight, upscale) over viral effects; only Water-Simulation, Cinemagraph and Slow-Motion-Control are effect-like.
- Because LTX-2 is 19B and LTX-2.3/2.5 are 22B, LTX-2 LoRA tensors are unlikely to even load on 2.5; together with the community report this means the seven official camera LoRAs are unusable on LTX-2.5 without retraining.
- None of the LTX-2.x adapters can be used by the current Effects workflow, which runs LTX-Video 2B 0.9.5.

### Gaps
- No Lightricks statement found on LTX-2 (19B) to LTX-2.3/2.5 compatibility; the "incompatible" claim rests on a community guide with a factual error.
- Which LTX-2.3 adapters are among the "small number of exceptions" on 2.5 is not listed by Lightricks.
- File size not fetched for Pixel-Spatial-Upscaler, SDR-To-HDR, Restore, Deblur, Day-To-Night, Decompression, Colorization (HF API rate limit).

## 2. Which community LTX-2.5 / LTX-2.3 / LTX-2 LoRAs are most used and best regarded (effects, camera, styles, product)?

### Takeaway
Native LTX-2.5 community LoRAs are few (23 non-Lightricks adapters on HF, 26 on Civitai, mostly character LoRAs), so the usable pool is LTX-2.3 LoRAs (119 HF adapters, 172 Civitai). The best-regarded community work is utility and control (Transition LoRA, Cameraman IC-LoRA, EditAnything, Ripple, Obscura Remova, Outpaint, CrossView) plus a coherent style series (claymation, paper cut-out, felt, puppet); true viral-effect LoRAs exist mainly on LTX-2 19B (inflate, cakeify, squish, tear, sprout, fluid burst, deep zoom) and would need retraining for 2.5.

## 3. Does a LoRA ecosystem exist for MiniMax H3?

### Takeaway
Yes, and it is the larger of the two: about 200 declared HF adapters (158 on MiniMaxAI/MiniMax-H3, 46 on Comfy-Org/MiniMax-H3) with about 1.2 million combined 30-day downloads, plus 387 Civitai LoRAs, built in the 11 weeks since the weights opened on 2026-08-03 and boosted by a Civitai H3 contest. MiniMax itself publishes no LoRAs; the "official" adapters are third-party speed LoRAs (lightx2v, Alibaba PAI) repackaged by Comfy. The ecosystem is strong in speed, realism, motion repair, styles and camera moves; it is thin on Higgsfield-style physical transformations.

## 5. How do they load in ComfyUI, and on Comfy Cloud?

### Takeaway
Plain LTX LoRAs and almost all H3 LoRAs use the stock LoRA loader; LTX IC-LoRAs need the Lightricks ComfyUI-LTXVideo nodes (`LTXICLoRALoaderModelOnly` + `LTXAddVideoICLoRAGuide`); a minority need extra custom nodes. ## 8. How deep is each model's LoRA ecosystem (honest read)?
