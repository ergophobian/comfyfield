# LoRAs and lightweight fine-tunes for ComfyField's audio, 3D and enhance models (checked 2026-10-19)

Scope: speech (Chatterbox, Chatterbox Multilingual, Fish Audio Drama 3, Qwen3-TTS), music (MiniMax Music 3, Stable Audio 3 Medium, ACE-Step 1.5 as the LoRA-rich alternative), sound effects and foley (HunyuanVideo-Foley), 3D (TRELLIS.2, Hunyuan3D 2.1, HY-World 2.0), enhance (SeedVR2, ESRGAN-family upscalers, upscale and restore LoRAs for Qwen-Image and FLUX 3 Image Klein).

How to read these notes:
- Every listed item was opened on its own page (Hugging Face card, Civitai API record, GitHub README or OpenModelDB record) on 2026-10-19.
- "dl" is Hugging Face "downloads last month" as shown on 2026-10-19. Civitai numbers are lifetime downloads and thumbs-up on 2026-10-19. "Not tracked" means the page shows no download count.
- Base model is written exactly as the page states it.
- Confidence: **High** = page is clear, loading path is documented or verified in ComfyUI source, and the author shows evidence. **Medium** = page is clear but there is no independent test, or the ComfyUI path is not verified. **Low** = thin card, unclear base or unclear loader.
- Excluded under the content rules and not listed: voice LoRAs of celebrities and of game or anime characters (their voice actors), LoRAs named after living musicians or bands, and repos flagged "Not-For-All-Audiences" or adult-oriented. Several such repos sit in the Qwen3-TTS, Chatterbox, MiniMax Music 3, ACE-Step, HunyuanVideo-Foley and SeedVR2 trees.

## Key question 1: How does ComfyUI load these adapters, natively or with which custom node? (applies to every pick below)

### Takeaway
ComfyUI core has dedicated LoRA key maps for ACE-Step 1.5 (official PEFT and LoKr formats), Qwen-Image (including 2.1) and FLUX 3, so those LoRAs load with the stock LoRA loader. Stable Audio 3, MiniMax Music 3's diffusion stage, SeedVR2 and TRELLIS.2 have no dedicated key map; their adapters need the author's code or a custom node. ESRGAN-family upscalers load natively through spandrel. Comfy Cloud can import LoRAs and upscalers from public Hugging Face or Civitai repos on Creator and Pro plans, `.safetensors` only.

### Cited Findings
- ComfyUI core `comfy/lora.py` (master, read 2026-10-19) has a block for `comfy.model_base.ACEStep15` that maps `base_model.model.*` keys ("Official base model loras") and `lycoris_*` keys ("LyCORIS/LoKR format") onto the ACE-Step 1.5 decoder. — [ComfyUI lora.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/lora.py)
- The same file maps ACE-Step v1 "Official ACE step lora format" (`comfy.model_base.ACEStep`). — [ComfyUI lora.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/lora.py)
- The same file maps Qwen-Image LoRAs (direct, `transformer.` prefix and SimpleTuner LyCORIS), and splits Qwen-Image 2.1's fused `img_mlp.gate_up` so LoRAs that address the halves still apply. — [ComfyUI lora.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/lora.py)
- The same file maps FLUX 3 (`comfy.model_base.Flux3`) LoRAs that address separate q/k/v projections onto the fused qkv weights. — [ComfyUI lora.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/lora.py)
- There is no model-specific block for Stable Audio, MiniMax Music 3 audio, SeedVR2, TRELLIS.2 or Hunyuan3D. A generic map accepts `lora_unet_*` and `diffusion_model.*` keys for any model. — [ComfyUI lora.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy/lora.py)
- ComfyUI's "Load Upscale Model" node uses spandrel, and imports `spandrel_extra_arches` for "non commercial upscale models" when present. — [ComfyUI nodes_upscale_model.py](https://github.com/comfyanonymous/ComfyUI/blob/master/comfy_extras/nodes_upscale_model.py)
- spandrel supports ESRGAN (incl. Real-ESRGAN, BSRGAN), Real-ESRGAN Compact, SwinIR, HAT, DAT, ATD, DRCT, PLKSR/RealPLKSR, MoESR, FDAT, GFPGAN and RestoreFormer; CodeFormer is only in `spandrel_extra_arches`. — [spandrel README](https://github.com/chaiNNer-org/spandrel)
- Comfy Cloud model import: "available for Creator and Pro plans only"; sources are public Hugging Face or Civitai repos; only `.safetensors`; folders in the import selector include `loras` and upscalers. — [Comfy Cloud import models](https://docs.comfy.org/cloud/import-models)
- The official ComfyUI ACE-Step 1.5 page mentions "Lightweight personalization through LoRA training in ComfyUI" but names no loader node. — [Comfy docs ACE-Step 1.5](https://docs.comfy.org/tutorials/audio/ace-step/ace-step-v1-5)

### Inferences
- Official-format ACE-Step 1.5 LoRAs (PEFT from the ACE-Step trainer, or LoKr from Side-Step) should load with the core "LoraLoaderModelOnly" node. Whether the same block covers the 4B XL models was not verified.
- LoRAs trained on the 2B ACE-Step 1.5 models cannot apply to the 4B XL models (different layer sizes). ComfyField's lineup pick is ACE-Step 1.5 XL turbo, so only XL-tagged LoRAs fit it.
- PEFT files for Stable Audio 3 or TRELLIS.2 use the authors' module names. They probably need key conversion before the core loader can apply them.
- FLUX.2 Klein 9B LoRAs (the large Civitai upscale ecosystem) do not fit FLUX 3 Image Klein. ComfyUI treats FLUX 3 as its own model class.

### Gaps
- No test run was done. Native loading of an ACE-Step XL LoRA, a TRELLIS.2 LoRA or a Stable Audio 3 PEFT LoRA in ComfyUI is not verified.
- Whether Comfy Cloud's preinstalled packs include the custom nodes named below (AusBoss nodes, ComfyUI-LTXVideo-Internal, TTS-Audio-Suite, ComfyUI-Qwen3-TTS) was not checked in this pass.

## Key question 2: Which genre, style or language LoRAs exist for the music models (ACE-Step, Stable Audio 3, MiniMax Music 3), and for sound effects and foley?

### Takeaway
MiniMax Music 3 has one product-ready adapter set: 16 MIT "particle sliders" for genre and lead-vocal gender that load in ComfyUI's stock LoRA node. ACE-Step 1.5 has the largest genre ecosystem (37 adapters across its Hugging Face trees, plus Civitai), but most are niche, unlicensed or non-commercial, and only a few fit the XL model. Stable Audio 3 has one adapter (Arabic maqam); its useful loop fine-tune (Foundation-1) is on the older Stable Audio Open 1.0. HunyuanVideo-Foley has no usable LoRA; the LoRA path for foley is LTX-2.3.

### Inferences
- For ComfyField's "Music" format on MiniMax Music 3, the particle sliders are the only adapter set that is licensed (MIT), documented for ComfyUI and generic (genres, not artists). They suit a "genre chip" UI.
- If ComfyField adds ACE-Step 1.5 XL turbo as the alternative, the Regrind LoRA is the one quality adapter worth testing; genre LoRAs on XL are very few (Ph0NK, concept sliders).
- Language packs for music models do not exist as such. Language quality depends on training data (e.g. Kawaii Future Bass is best with Japanese lyrics; the Chinese rap LoRA is v1 only).
- Sound effects (Stable Audio 3 Small-SFX and Medium) have no adapters. Prompting is the only control today.

### Gaps
- Several ACE-Step 1.5 adapters were seen only in the API list, not opened, so they are not catalogued: nepali-folk, russian-pop, Zulu, synthpop, funk50 DoRA, ambient_dream1, raspy-vocal set, symphonic metal, dark-blues XL, Nekochu pop-electro XL.
- No MiniMax Music 3 adapter for language or lyrics pronunciation was found.
- Whether the particle sliders work with Comfy Cloud's Music 3 text encoder file (separate vs merged qkv) is not verified.
- No evidence that LTX-2.3 foley LoRAs run on LTX-2.5.

## Key question 3: Which emotion, style or language adapters exist for the TTS models, and is LoRA training supported by their repos?

### Takeaway
Chatterbox has the richest language ecosystem: Resemble AI ships six official single-language fine-tunes (MIT), and the community adds dialects (Saudi, Egyptian, German with non-verbal tags, eight Indic languages by LoRA). Qwen3-TTS has official single-speaker fine-tuning for the Base models plus two strong adapters: emotion tags (English) and Russian word stress. Fish Audio Drama 3 has no adapters and no documented fine-tuning. The Chatterbox repo itself documents no fine-tuning or LoRA.

### Inferences
- For ComfyField's Comfy Cloud path, the official Chatterbox language packs are the highest-value audio "adapters", but they need a node that can swap the T3 checkpoint. Fill-ChatterBox does not document that, so this may need a Runpod path or a small node change.
- Emotion is better handled by built-in controls (Chatterbox `exaggeration`, Turbo tags, Drama 3 bracket direction) than by LoRAs. The Qwen3-TTS emotion-tag adapter is the exception, and only for English preset voices.
- Language and dialect coverage is where TTS fine-tunes earn their place (Indic, Saudi, Russian stress).

### Gaps
- Many community Chatterbox language fine-tunes (Persian, Czech, French, Finnish, Uzbek, Kazakh, Welsh, Hausa, Yoruba, Igbo) were seen in the tree but not opened.
- No Fish Drama 3 fine-tuning path is documented. Fish's older fish-speech repo had LoRA fine-tuning for earlier models, but that was not verified for Drama 3.
- No adapter adds emotion control to Chatterbox Multilingual languages beyond the built-in slider.

## Key question 4: Which LoRAs or fine-tunes exist for TRELLIS.2, Hunyuan3D or HY-World (low-poly, game-ready, stylized)?

### Takeaway
No low-poly, game-ready or stylized LoRA was found for any of the three 3D models. The TRELLIS.2 adapter tree has three entries: a Minecraft texture LoRA, a 4-step speed distillation (SMD) and a single-photo scene model (BuildRome, non-commercial). The useful 3D add-ons are fine-tuned companions: Hunyuan3D-Part (split a mesh into parts), UltraShape (geometry refinement), and AniGen (animatable assets, on TRELLIS v1). HY-World 2.0 has no adapters, but its own panorama stage ships as a LoRA for Qwen-Image-Edit-2509.

### Inferences
- Style for 3D is best set on the input image, not on the 3D model. ComfyField already has a "Low poly" Look on FLUX 3 Image Klein and runs "Text to 3D model" as FLUX 3 Klein then TRELLIS.2, so a low-poly or toy-figure image feeds TRELLIS.2 directly. Polygon count is a decimation setting, not a style.
- A real "game-ready low-poly" TRELLIS.2 LoRA would need training on a low-poly mesh dataset (TRELLIS.2 training code, or fal's trainer). No one has published one.
- HY-Pano-2-Qwen is the most practical piece of HY-World 2.0 for ComfyField: a LoRA on a model already in the Comfy catalog (Qwen-Image-Edit 2509).

### Gaps
- The shape-stage Minecraft LoRA (TRELLIS2-Minecraft-LoRA-v1) and SMD-Hunyuan3D-2.1-Shape were not opened.

- No ComfyUI node loads TRELLIS.2 or Hunyuan3D LoRAs today, as far as found.

## Key question 5: Which LoRAs improve upscaling and restoration (SeedVR2, Qwen-Image, FLUX 3 Klein, ESRGAN family, video)?

### Takeaway
SeedVR2 has no adapter ecosystem; its only add-on is a 1.4B distillation for speed. The working restore and upscale LoRAs sit on Qwen-Image-Edit (2509 and 2511), Qwen-Image 2.1 and, very recently, FLUX 3 Image Klein (25 adapters in its two trees, one of them a restore LoRA). The best-matched pick for "Restore an old photo" is ausboss's Qwen-Image 2.1 Restore LoRA, which exactly fits the format's base and reports measured gains. ### Inferences
- "Restore an old photo" should use ausboss's Qwen-Image 2.1 Restore LoRA at strength 1.0 (0.5 for blurry prints), then SeedVR2. Its license is research-only, the same as Qwen-Image 2.1 itself.
- For a commercially licensed restore path, the Qwen-Image-Edit-2511 LoRAs (Apache) are the fallback. vafipas663's 2509 LoRA covers the widest list of degradations but is GPL-3.0 and untested on 2511.
- SeedVR2 needs no LoRA. Its value is that it is prompt-free and stays faithful. LoRA redraws (Qwen, FLUX 3) add detail but can change faces, which both ausboss cards say openly.
- The LTX-2.5 Pixel-Spatial-Upscaler should not replace SeedVR2 on user footage. Its own card warns against factual live-action use.

### Gaps
- No colourization LoRA for still photos on Qwen-Image 2.1 or FLUX 3 Klein was found (only manga colorizers). "Bring back the color" in the Restore format relies on the edit model's prompt.
- Popularity of the brand-new FLUX 3 Klein LoRAs is not meaningful yet.
- Whether Comfy Cloud ships the AusBoss nodes is unknown.

## Key question 7: Where are LoRAs not the right tool? (honest read)

### Takeaway
For voices, sound effects, foley and 3D style, LoRAs are the wrong lever today. Voices clone zero-shot from a reference clip, emotion is a built-in control, sound effect models have no adapter ecosystem, and 3D style is set on the input image. LoRAs are the right lever for image restoration and upscaling, for music genre steering, and for adding languages or dialects to TTS.

### Cited Findings
- Chatterbox clones from `audio_prompt_path` and controls emotion with `exaggeration`; the README documents no fine-tuning. — [Chatterbox GitHub](https://github.com/resemble-ai/chatterbox)
- Drama 3 clones from a reference clip with its transcript and is directed with bracketed text; no adapters exist in its tree. — [drama-3 card](https://huggingface.co/fishaudio/drama-3), [HF API drama-3](https://huggingface.co/api/models?filter=base_model:adapter:fishaudio/drama-3&sort=downloads&limit=100)
- Qwen3-TTS instruction control (emotion, prosody) is built into the CustomVoice and VoiceDesign models; official fine-tuning targets a single speaker on Base. — [Qwen3-TTS GitHub](https://github.com/QwenLM/Qwen3-TTS), [finetuning](https://github.com/QwenLM/Qwen3-TTS/tree/main/finetuning)
- The Qwen3-TTS 0.6B-Base adapter tree is dominated by per-character voice LoRAs and per-speaker accent runs (24 adapters, several sets for named game characters). — [HF API 0.6B-Base](https://huggingface.co/api/models?filter=base_model:adapter:Qwen/Qwen3-TTS-12Hz-0.6B-Base&sort=downloads&limit=100)
- TTS-Audio-Suite: "RVC is the only engine with training support right now", which is the per-voice model route for singing conversion. — [TTS-Audio-Suite](https://github.com/diodiogod/TTS-Audio-Suite)
- Stable Audio 3 Small-SFX and Small-Music have 0 adapters; SA3 Medium has 1. — [HF API SA3 small-sfx](https://huggingface.co/api/models?filter=base_model:adapter:stabilityai/stable-audio-3-small-sfx&sort=downloads&limit=100), [SA3 medium](https://huggingface.co/api/models?filter=base_model:adapter:stabilityai/stable-audio-3-medium&sort=downloads&limit=100)
- HunyuanVideo-Foley ships inference only. — [HunyuanVideo-Foley GitHub](https://github.com/Tencent-Hunyuan/HunyuanVideo-Foley)
- Upscale LoRA authors themselves call the result "a redraw, not a recovery"; the FLUX 3 restore gain is "small". — [Qwen 2.1 Restore](https://huggingface.co/ausboss/Qwen-Image-2.1-Restore-LoRA), [Klein Restore](https://huggingface.co/ausboss/FLUX-3-Image-Klein-Restore-LoRA)
- Many music LoRAs carry no license or a non-commercial one (Xanthius sliders, worstplayer: none stated; Regrind: CC BY-NC-SA; Naija: CC BY-NC; ACE-Step's own New Year LoRA: "commercial use is prohibited"). — [Xanthius](https://huggingface.co/Xanthius/Ace-Step-1.5-XL-Concept-Sliders), [Regrind](https://huggingface.co/mdmachine/ACEStep-XL-Regrind-V1), [New Year LoRA](https://huggingface.co/ACE-Step/ACE-Step-v1.5-chinese-new-year-LoRA)

### Inferences
- A "voice LoRA" store would mostly attract clones of real or character voices, which conflicts with ComfyField's likeness-consent format. The safer product is "save a voice from your own sample" (reference clip or embedding) plus consent.
- For music, a curated genre chip set (MiniMax sliders) is the right size. Open-ended community genre LoRAs add licensing and quality risk.
- For upscaling, LoRA redraws should be an opt-in "more detail" mode next to a faithful SeedVR2 default, because redraws can change faces.

### Gaps
- No user study compares LoRA restore and SeedVR2 on old family photos; only the authors' own metrics exist.

## Key question 8: Novel or interesting (capabilities that could become a new ComfyField service)

### Takeaway
Six adapters point to new services: restore damaged music, restore and colorize old video, split a 3D model into parts, rigged 3D characters from one photo, photo to 3D scene, and joint audio-visual lip dubbing. Each one names a ComfyField service it could become.

### Cited Findings
- **"Restore a song" (new Enhance format, audio):** MiniMax Music 3 latent refiner rebuilds a clean version of degraded music and keeps vocals and arrangement; 7x realtime end to end on one L40S. — [latent refiner](https://huggingface.co/terminusresearch/minimax-music3-latent-refiner-v0.10)
- **"Restore old video" and "Colorize a video" (new Enhance formats):** LTX-2.5 Restore IC-LoRA handles tape, sepia, B&W colour, flicker and scratches; the Colorization IC-LoRA colours grayscale video. — [Restore](https://huggingface.co/Lightricks/LTX-2.5-22b-IC-LoRA-Restore), [Colorization](https://huggingface.co/Lightricks/LTX-2.5-22b-IC-LoRA-Colorization)
- **"Split into parts" for 3D (new 3D format, mirrors the image "Split into layers"):** Hunyuan3D-Part segments any mesh (P3-SAM) and generates complete parts (X-Part). — [Hunyuan3D-Part](https://huggingface.co/tencent/Hunyuan3D-Part)
- **"Rigged character figure" (upgrade of Character figure):** AniGen makes animatable 3D assets from one image with controllable joint density (SIGGRAPH 2026). — [AniGen](https://huggingface.co/VAST-AI/AniGen)
- **"Photo to 3D scene" (new Scenes and games format):** BuildRome builds a metric scene mesh, including hidden geometry, from one photo (non-commercial). — [BuildRome](https://huggingface.co/AppliedIntuitionResearch/BuildRome)
- **"Lip dub" (Translate / Lipsync alternative):** LTX-2.3 DubIt IC-LoRA does "lip dubbing on top of the LTX model" with video and audio control (paper "JUST-DUB-IT"); 2,457 dl, 151 likes. — [DubIt](https://huggingface.co/Lightricks/LTX-2.3-22b-IC-LoRA-DubIt)
- **"Blend two voices" (Voice clone option):** Qwen3-TTS voice embeddings can be mixed with SLERP or weighted averaging. — [Voice-Embedding](https://huggingface.co/marksverdhei/Qwen3-Voice-Embedding-12Hz-1.7B)
- **"A cappella vocals" (Music option):** the ACE-Step vocals LoRA halves the backing-track share while keeping lyrics. — [acestep-vocals-lora](https://huggingface.co/TTS-AGI/acestep-vocals-lora)
- **Expressive TTS as an LTX IC-LoRA:** Resemble's Dramabox is an IC-LoRA on the LTX-2.3 3.3B audio-only model; the prompt controls speaker, emotion, laughs and sighs; optional 10 s cloning; about 24 GB VRAM; English; LTX-2 Community License; 449 dl, 324 likes. — [Dramabox](https://huggingface.co/ResembleAI/Dramabox)

### Inferences
- The LTX family now covers foley and dubbing (LTX-2.3 22B), restore, colorize and deblur (LTX-2.5 22B; the Restore LoRA also runs on 2.5 unchanged), and expressive TTS (LTX-2.3 3.3B audio-only) as LoRAs. ComfyField already runs LTX-2.5 in several formats (Multi-shot scene, Promo poster, Just for fun videos), so the 2.5 IC-LoRAs could share that loaded model.

### Gaps
- None of the novel items was run. ComfyUI support exists only for the LTX IC-LoRAs (through ComfyUI-LTXVideo); the others need custom code on a Pod.
