# Contributing

Thanks for helping build ComfyField. People and coding agents follow the same rules, written in [AGENTS.md](AGENTS.md). Read it first.

1. Pick an open issue. `agent-ready` issues are fully specified; `good first issue` ones are small.
2. Comment that you are taking it, then branch `issue-<number>-<short-name>`.
3. Open a PR with the template filled in, including a screenshot or GIF.
4. CI must pass on Linux, macOS and Windows. A maintainer reviews and merges.

New ideas: open a Task issue with context and acceptance criteria. Bugs: use the Bug form and include your OS and Node version.

AI-written code is welcome. Say which agent wrote it in the PR, and review it yourself before asking for review.
