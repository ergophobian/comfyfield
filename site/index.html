ComfyField is an open-source creative studio for images, video and audio. It runs on your computer, with your own keys, on the Comfy Developer Platform.

Cinema turns one idea into a scene you can edit

Rendered with LTX-2.5 on Comfy Cloud

  1. PlanShape each shot's prompt, camera move and length before anything renders.
  2. RenderEvery shot runs with LTX-2.5 on Comfy Cloud, sound included.
  3. ReviewApprove a shot to send it to the scene, or rerun only that one.
  4. StitchJoin the approved clips on your machine and export the MP4.

The rest of the studio works the same way

One composer

Image, video and audio start from the same prompt bar. Pick any connected model, add references, and run one prompt or a whole batch.

Flows, with agents in the loop

Every Cinema scene is saved as a Flow you can open on the canvas. Approve gates hold each step until you press Send. Agents build and edit the same flows through the MCP server, and stop at the same gates.

This flow was built by an agent through MCP.

A Library for every take

Generations land in the Library, next to the characters, products, brand kits and voices you reuse across tools.

Run it locally

  1. Clone the repositoryYou need Git and Node.js 22 or newer.
  2. InstallOne npm install pulls everything the studio needs.
  3. Start the studioOpen localhost:5173 in your browser.
  4. Add a Comfy keyIn Connections, paste a key from platform.comfy.org and choose Save and test.

Generation uses your own provider credits.

Terminal
git clone https://github.com/ergophobian/comfyfield.git
cd comfyfield
npm install
npm run dev
