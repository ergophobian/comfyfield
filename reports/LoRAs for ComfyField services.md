# Video and edit LoRAs carry ComfyField furthest

The LoRAs that would make ComfyField excel sit mostly on its video and edit models, not on the image model that runs most of its Looks. MiniMax H3 gained about 200 Hugging Face adapters and 387 Civitai LoRAs in eleven weeks. That is enough for move-specific LoRAs on about 34 of the 72 camera moves, plus people realism, UGC and ASMR audio, and character swap. LTX-2.5 has 15 official Lightricks adapters (Alpha-Gen, Layout-To-Render, Cinemagraph, Restore, Clean-Plate and others) that upgrade Enhance and Video edits directly. Qwen-Image-Edit 2511 has the deepest edit ecosystem, mostly under Apache-2.0 or MIT. Qwen-Image 2.1 already has LoRAs built for exactly the right base for Expand, Restore, Try on, Place a product and Face swap. FLUX 3 Image Klein runs 24 of the 27 Looks, but it is days old and has only about 40 LoRA files, mostly tools. Its Looks should therefore borrow mature Z-Image Turbo or Krea 2 LoRAs, or lean on FLUX 3's own multi-reference input. Two inventory mistakes block upgrades. The 143 LTX Effects run on LTX-Video 2B 0.9.5, which cannot load any LTX-2.x LoRA. "Remove text from a video" is mapped to Clean-Plate, which removes people, not text. Shipping is the hardest limit. Comfy Cloud preinstalls 652 LoRAs, referenced by filename. They include the Qwen 2511 angle and relight files, but none for FLUX 3 or HiDream-O1, one for LTX-2.5 and five for H3. Most picks therefore need a RunPod Pod, or each user must import the file on a Creator plan. The cheapest contest wins among the novel finds are transparent video, 3D blockout to render, cinemagraphs, seamless H3 orbits, day-to-night relighting and old-video restore. The search also supports two whole new pages: "Game assets" and "VR and 3D". Audio and 3D are the exception. Voices clone zero-shot and 3D style comes from the input image, so LoRAs help there only with music genres and TTS languages. No LoRA was test-run. Every count and quality claim comes from model cards and the Hugging Face and Civitai APIs on 2026-10-19.

## Ecosystem depth and Cloud's 652 preinstalls set the limits

How deep each base model's LoRA ecosystem is decides more than any single LoRA. **MiniMax H3 opened its weights on 2026-08-03 and now has 158 adapters on the MiniMaxAI repo and 46 on the Comfy-Org repack, with about 1.2 million combined 30-day downloads**, plus 387 Civitai LoRAs. A Civitai H3 contest helped drive that growth ([HF API, H3 adapters](https://huggingface.co/api/models?filter=base_model:adapter:MiniMaxAI/MiniMax-H3&sort=downloads&limit=1000); [Civitai API, H3](https://civitai.com/api/v1/models?types=LORA&sort=Most%20Downloaded&nsfw=false&limit=100&baseModels=MiniMax%20H3)). LTX-2.5 has few community LoRAs but the strongest official set. **Lightricks published 15 LTX-2.5 adapter repos between 2026-08-11 and 2026-09-28** ([Lightricks on HF](https://huggingface.co/Lightricks)). Lightricks also states that "the large majority of LoRAs and IC-LoRAs trained on LTX-2.3 run on LTX-2.5 without changes", so LTX-2.5 inherits about 120 LTX-2.3 adapters ([Lightricks/LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5)). At the other end, FLUX 3 Image Klein had only 25 Hugging Face adapters and 19 SFW Civitai LoRAs on 2026-10-19. Authors retrain rather than port FLUX.2 Klein files, because the transformer (5.6B against 4B or 9B) and the text encoder differ ([BFL blog](https://bfl.ai/blog/flux-3-image-klein); [Civitai 360 Seamfix, separate F3 file](https://civitai.com/models/2709848?modelVersionId=3409354)). HiDream-O1 has zero Hugging Face adapters and 30 Civitai LoRAs, none above 200 downloads ([HF API](https://huggingface.co/api/models?filter=base_model:adapter:HiDream-ai/HiDream-O1-Image); [Civitai API](https://civitai.com/api/v1/models?types=LORA&baseModels=HiDream-O1&nsfw=false)).

Qwen-Image 2.1 needs one warning. It is a new 7B single-stream model, so no Qwen-Image-Edit 2509 or 2511 LoRA loads on it. LoRA authors say this directly: the 2.1 Stop-Motion LoRA "is not an adapter for older Qwen-Image releases" ([ProCreations](https://huggingface.co/ProCreations/stopmotion-consistency-v1-lora); [Qwen/Qwen-Image-2.1](https://huggingface.co/Qwen/Qwen-Image-2.1)). Most ComfyField image edits run on 2.1 today. Only the month-old 2.1-native LoRAs apply to them as wired.

The way ComfyField runs models turns this map into shipping rules. **A shipped format can rely only on Cloud's preinstalled LoRAs, named by exact filename in a core `LoraLoader` or `LoraLoaderModelOnly` node.** Any other LoRA must either be imported by each user (Creator plan, $35 a month, private to that user) or run on a Pod ([Comfy docs: import models](https://docs.comfy.org/cloud/import-models); [comfy.org/pricing](https://comfy.org/pricing)). The Pod downloader accepts public Hugging Face `owner/repo` sources only, pins each file by sha256 and sends no token. A new Hugging Face LoRA therefore needs one `MODEL_FILES` entry. A Civitai LoRA or a gated Hugging Face LoRA, which includes every official Lightricks LTX-2.5 adapter, needs new downloader code or an ungated mirror whose hash matches. ComfyField already uses that mirror pattern for the gated LTX-2.5 base ([shared/modelFiles.js on branch issue-89-skills-library](../.claude/worktrees/skills/shared/modelFiles.js); [server/pod-statusd.py](../.claude/worktrees/skills/server/pod-statusd.py)). ComfyUI v0.41.1 maps LoRA keys natively for every target base, including Qwen-Image 2.1, FLUX 3, Z-Image, HiDream-O1, LTX and H3. Core `GetICLoRAParameters` and `LTXVAddGuide` cover LTX IC-LoRAs. So the safe rule is to use core loaders only, because the Pod starts with every custom node disabled except FreeVideo ([ComfyUI lora.py @45bf90d](https://github.com/comfyanonymous/ComfyUI/blob/45bf90d1c91eecd782643346dcfb73cb0017667f/comfy/lora.py); [server/podBoot.js](../.claude/worktrees/skills/server/podBoot.js)). LoRAs that need custom nodes are out of reach on both backends for now: the Krea 2 edit stack, PixelSmile, CrossView-Warp, Meridian and the H3 PDD Acc LoRAs. For the contest, each format should stack one task LoRA plus at most one speed LoRA. Lightricks warns against any universal strength cap and asks that each LoRA be checked alone first ([LTX docs: LoRAs](https://docs.ltx.io/open-source-model/usage-guides/lo-ra)). The orchestration pages (Explore, Apps, Assistant, Assets, Skills) run no model of their own. Skills such as the Product photoshoot skill inherit the picks of the formats they call. Canvas (Flows) is where LoRA tools can surface as nodes, for example "Pull alpha", "Ripple to video" or "Paint VFX" in the novel-finds table below.

## MiniMax H3 LoRAs cover half the camera moves and the people formats

The 72 camera moves already run prompt-only on H3, so the H3 ecosystem plugs straight in. **A move-specific H3 LoRA exists for about 34 of the 72 moves, and a generic Camera Motion LoRA covers about 15 basic dolly, pan, tilt, crane and tracking moves.** The flagship is pablodawson's 360 Orbit LoRA (27,620 downloads in 30 days, 515 likes). It uses the same photo as the first and last keyframe, and the camera circles a frozen subject and lands back on frame one, so orbits chain without a seam. Without the LoRA, the base model "barely moves" in this setup ([pablodawson/MiniMax-H3-360-Orbit-LoRA](https://huggingface.co/pablodawson/MiniMax-H3-360-Orbit-LoRA)). H3 LoRAs target specific variants (FL2VA, Ref2VA, T2V), and H3 is guidance-distilled, so CFG stays at 1 ([akhaliq claymation card](https://huggingface.co/akhaliq/MiniMax-H3-Claymation-Style-LoRA)). Effect and camera LoRA authors advise about half strength when a turbo LoRA is stacked ([Bullet Time](https://civitai.com/models/2934116); [SMACK!](https://huggingface.co/LeechTM/SMACK)). For speed, Cloud already preinstalls the lightx2v 8-step FL2V turbo. larryvrh's Turbo v4 is the most-downloaded alternative, with 205,560 downloads in 30 days ([larryvrh/MiniMax-H3-Turbo-Lora](https://huggingface.co/larryvrh/MiniMax-H3-Turbo-Lora)).

## Effects must leave LTX-Video 2B before any LoRA applies

The Effects catalog is where Higgsfield-style quality depends most on LoRAs, and it is also the most blocked. **143 of the 166 Effects load `ltx-video-2b-v0.9.5`, so none of the LTX-2.x LoRAs in this search can apply to them as wired** ([public/workflows/video_ltx.json](../public/workflows/video_ltx.json); [inventory](../research_notes/LoRAs%20for%20ComfyField%20services/00%20service%20inventory.md)). LoRA weights also do not carry across LTX generations: effect LoRAs exist for LTXV 13B, LTX-2 19B and LTX-2.3/2.5 22B, and each needs its own base. A community guide says LTX-2 LoRAs "produce garbage output" on LTX-2.3. However, the same page misstates LTX-2's size, so treat that claim as likely, not proven ([ltxworkflow guide](https://ltxworkflow.com/resources/community/ltx-23-vs-ltx-2-upgrade-community-guide)).

The two research tracks counted coverage differently, and together they point to a clear split. **On Wan 2.2 I2V A14B, a ready effect LoRA exists for about 38 of the 166 Effects, with partial matches for about 37 more.** On LTX-2.5 and H3 combined, only 7 Effects have a direct LoRA (Flood, Claymation, Everyone freezes, Frozen moment, Frozen diner orbit, Datamosh, Zero gravity), 70 have any match and 96 have none. The Wan coverage comes from a few prolific authors. hxxwoq2222 made Time-lapse, Earth Zoom Out, Eyes in, Frozen, Thunder God's Eyes, Titanscape and Petals. artificialguybr's CC0 Redmond set covers Disintegration, Explosion, Spontaneous Combustion, Metalcification, SkinMorph and Disappearing. luisa_caotica made Bullet Time, Fly Away, Stop Motion, Glitch and Nuke. kabachuha made Claymation Transformation ([hxxwoq2222 Time-lapse](https://civitai.com/models/1877924); [Redmond Disintegration](https://huggingface.co/artificialguybr/Disintegration-Redmond-WAN2-I2V-14B); [luisa_caotica Bullet Time](https://civitai.com/models/2084396); [kabachuha Claymation](https://civitai.com/models/1659949)). On Wan 2.2, most effect LoRAs load on the high-noise expert only, so one file per effect is enough ([hxxwoq2222 note](https://civitai.com/models/1882717)). The default stack is the lightx2v 4-step distill pair, which has 10.9 million all-time downloads. Leave FusionX out: its card limits it to non-commercial use, and the InfiniteTalk team reports color shift and identity loss on long clips ([lightx2v/Wan2.2-Distill-Loras](https://huggingface.co/lightx2v/Wan2.2-Distill-Loras); [InfiniteTalk README](https://github.com/MeiGen-AI/InfiniteTalk)).

The cheapest Effects win is a set ComfyField does not offer at all. **The classic viral effects (squish, inflate, cakeify, crush, deflate, muscle, 360 spin) all have ready, Apache-licensed LoRAs, and Remade's 360 Rotation alone has 176,262 Hugging Face downloads**. They were trained on Wan 2.1 480p, and Wan 2.2 retrains exist for squish and cake ([Remade-AI/Rotate](https://huggingface.co/Remade-AI/Rotate); [Remade-AI/Squish](https://huggingface.co/Remade-AI/Squish); [kabachuha Squish One Hand](https://civitai.com/models/1957482); [Cut Anything, it's a cake](https://civitai.com/models/2168151)). Moderate the Muscle LoRA before use, because its Civitai gallery is flagged at nsfwLevel 15. H3 adds the effects Wan lacks: Frozen World time-freeze, zero gravity, datamoshing, clay morphing and SMACK! impacts. With these, the three Seedance formats (Melt, Zero gravity, Claymation) could move onto open weights ([Frozen World](https://civitai.com/models/2986051); [zero gravity 101](https://civitai.com/models/2952734); [Datamoshing](https://civitai.com/models/2979274); [H3 Claymation Transformation](https://huggingface.co/kabachuha/mh3-r2va-claymation-transformation)). LTX-2.5's IC-LoRA tools turn other partial matches into two-pass recipes. Water-Simulation adds water to a finished clip for Flood and Dachshund surf. AInVFX fluid turns painted blobs into fire or smoke for Set on fire, Fire breath and Puff of smoke. Ripple carries an edited first frame through a whole clip, which suits material changes such as Turn to ice or Chrome body ([Water-Simulation](https://huggingface.co/Lightricks/LTX-2.5-22b-IC-LoRA-Water-Simulation); [AInVFX fluid](https://huggingface.co/AInVFX/ainvfx-fluid); [LTX Ripple](https://huggingface.co/WepeNerd/LTX-Ripple)).

## Official IC-LoRAs and edit-model hygiene upgrade Video edits and Enhance

For Video edits, the biggest gains come from correct speed and quality LoRAs on the edit models ComfyField already runs, not from effect LoRAs. **The official Bernini-R ComfyUI template reuses one Wan 2.1 lightx2v LoRA at 3.0 and 1.5, which "often shows blurry fingers on movement, laggy or glitchy motion". rzgar's Bernini-specific 4-step pair (35,641 downloads) replaces it at 1.0 on both experts** ([rzgar/Bernini-R-LightX2V-4step-loras](https://huggingface.co/rzgar/Bernini-R-LightX2V-4step-loras)). SCAIL-2 has two official LoRAs. A DPO LoRA "does not only alleviate hands distortion, but also improved the synchronization of the lips and eyes", and a relighting LoRA blends the swapped character into the target scene's light ([SCAIL-2 README](https://github.com/zai-org/SCAIL-2)). Wan Animate 2 has no LoRAs. The Wan team advises against using Wan 2.2 LoRAs on Animate, and Animate 2's distilled checkpoint already runs in 10 steps ([Wan2.2-Animate-14B](https://huggingface.co/Wan-AI/Wan2.2-Animate-14B); [Wan2.2-Animate-2-14B](https://huggingface.co/Wan-AI/Wan2.2-Animate-2-14B)). InfiniteTalk runs best with the lightx2v I2V 480p LoRA at 4 steps, text guide 1 and audio guide 2 ([InfiniteTalk README](https://github.com/MeiGen-AI/InfiniteTalk)).

The official LTX-2.5 IC-LoRAs act as a post-production toolkit. **Alpha-Gen makes a grayscale alpha matte from any RGB clip, handling hair, smoke, glass and water with no prompt or mask (12,705 downloads in 30 days)**. Clean-Plate removes people and vehicles without a mask. ## FLUX 3 Klein's Looks must borrow Z-Image and Krea 2 LoRAs

FLUX 3 Image Klein runs most of the visual personality of ComfyField: 24 Looks, 11 fun formats, 6 Characters formats, Storyboard and the Explainer frames. The mature looks live on two other bases. **Z-Image Turbo has an Apache-2.0 base, runs in 8 steps and carries proven realism, film and pixel-art LoRAs, such as Realistic Snapshot v5 (42,241 version downloads) and GrainScape**. Krea 2 is broader. It offers 9 official style LoRAs, phone-era realism, and a full edit stack that mostly needs custom nodes. Its licence caps commercial use at $1M revenue and makes content filtering mandatory ([Realistic Snapshot](https://civitai.com/models/2268008?modelVersionId=2617751); [Krea 2 LoRA collection](https://huggingface.co/api/collections/krea/krea-2-loras); [krea.ai licensing](https://www.krea.ai/krea-2-licensing)). Krea 2's best edit adapter, Identity Edit (153,255 downloads in 30 days, 867 likes), is "free for personal / non-commercial use; commercial use needs a license from me". Its Civitai flags say otherwise, so treat it as blocked until the author answers ([conradlocke/krea2-identity-edit](https://huggingface.co/conradlocke/krea2-identity-edit)). The pragmatic split has three parts. Keep FLUX 3 Klein wherever its multi-reference editing carries identity (characters, restyle, headshots). Add its tool LoRAs to Expand, Wallpaper and Restore. Point LoRA-dependent Looks at Z-Image Turbo first, because of its licence, and at Krea 2 where the look exists only there.

## LoRAs help audio and 3D only for genres, languages and restore

For voices, sound effects and 3D style, LoRAs are the wrong lever today. Chatterbox clones from a reference clip and controls emotion with an `exaggeration` setting. Fish Audio Drama 3 has zero adapters. Stable Audio 3's sound-effect models have none. HunyuanVideo-Foley ships inference code only ([Chatterbox](https://github.com/resemble-ai/chatterbox); [drama-3 card](https://huggingface.co/fishaudio/drama-3); [HunyuanVideo-Foley](https://github.com/Tencent-Hunyuan/HunyuanVideo-Foley)). **The exceptions are measurable. ntc-ai's 16 MIT "particle sliders" give MiniMax Music 3 one-click genre and vocal-gender chips through the stock LoRA loader. Language fine-tunes fix specific gaps: a Russian-stress adapter for Qwen3-TTS raises stress compliance from 17% to 96%** ([particle sliders](https://huggingface.co/ntc-ai/minimax-music3-particle-sliders); [ru-stress](https://huggingface.co/siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf)). Two cautions apply to the Music 3 sliders. They need a text encoder with separate q/k/v projections, and nobody has checked Comfy Cloud's Music 3 encoder file for this. No style LoRA exists for TRELLIS.2 or Hunyuan3D, so 3D style should be set on the FLUX 3 input image.

## Forty novel finds point to two new pages

The most impressive finds share one pattern. **Each takes a video or edit model and makes it produce a different kind of output: alpha mattes, seamless loops, stereo pairs, five-view sheets, HDR frames or sprite sheets.** Prompting cannot fake these outputs, so they are where an open stack can visibly beat Higgsfield's fixed presets. A keyword search of the Higgsfield audit finds nothing for "sprite", "turnaround", "cinemagraph", "illusion" or "audio reactive" ([Higgsfield audit](../research_notes/Higgsfield%20feature%20audit/README.md)). ## Conclusion

The search changes the question from "which LoRA" to "which base". Moving the 143 Effects off LTX-Video 2B unlocks more than any single LoRA. On Wan 2.2 they gain about 38 ready effect LoRAs and the missing classic viral set. On LTX-2.5 they gain the official IC-LoRA tools. The Qwen image edits face a similar choice. Qwen-Image 2.1 has the stronger base and a few precise new tools. Edit 2511 has a far larger ecosystem, Apache or MIT terms and Cloud preinstalls. The services that lack 2.1 LoRAs (relight, product shots, poses) are the ones to route to 2511. A clear division of labour also emerges. LTX-2.5 is ComfyField's editing and VFX-tool model. MiniMax H3 is its generation and style model. FLUX 3 Klein should keep only the jobs where multi-reference identity matters and its four tool LoRAs exist, until its ecosystem matures after the contest.

The enabling work is infrastructure, not curation. ComfyField needs a "LoRA preset" record that stores the base, file, strength, trigger template, image order, mask color, steps, CFG and whether a turbo LoRA is allowed. It also needs downloader support for Civitai and gated Hugging Face sources, or hash-pinned mirrors. Without these, most picks above cannot leave a Pod, and none can run on Cloud unless Comfy preinstalls them. Where no LoRA exists, the cards show that ComfyField can train its own cheaply: about $3 for an H3 style and $12.50 for a capability LoRA. That makes a small custom pack for the top unmatched Higgsfield effects realistic (clones, portal, angel wings, snow globe, hug). Every pick in this report still needs a visual A/B test. A LoRA whose keys fail to map loads silently with no effect.
